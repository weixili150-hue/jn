# 环境熵 (Entropy Observer) — 设计规格

> 赛博塔罗 × 数字占卜 × 环境熵决策工具
> 首要平台：**手机浏览器**（移动优先）
> 桌面端作为放大版适配

---

## 产品概述

用户输入一个需要决策的选项 A/B，AI 以"环境熵观测器"身份随机提问 3-4 个高度抽象的信号采集问题，综合后输出"世界偏向 A 还是 B"及一句宿命感判词。

核心洞察：用户缺的不是答案，是一个让他们心安理得选 A 的理由。

---

## 页面流程

```
① Oracle Splash (3秒) → ② 主题选择 → ③ A/B 输入 → ④ 逐个浮现提问(3-4轮) → ⑤ Loading 仪式 → ⑥ 结果神谕
```

---

## 移动端设计原则

- 所有内容单列布局，不设多列
- 最小触摸目标 44×44px（Apple HIG 标准）
- 基准字号 16px（防 iOS 自动缩放）
- 不依赖 hover 交互
- 输入框和 chip 选择器适配拇指区域
- 键盘弹起时自动调整视口
- 无横向滚动
- 支持 `prefers-reduced-motion`
- `font-display: swap` 防止 FOIT

## 三大主题

### Mystic Void（暗夜神秘）
- 适用：深夜、情感问题、孤独状态
- 配色：微暖黑底 `#07060A` + 暗金 `#C4A35A` + 暖白文字 `#EDE8DF`
- 字体：Playfair Display(标题) + Inter 300(正文) + Noto Serif SC(中文)
- 氛围：20-30 粒 1px 金/白粒子缓慢布朗运动，径向微光晕，无网格

### Neon Entropy（赛博终端）
- 适用：冲动决策、高情绪、赛博沉浸
- 配色：深紫黑 `#060012` + 电紫 `#B44DFF` + 氰蓝 `#00E5FF` + 品红 `#FF2D95`
- 字体：JetBrains Mono(全族等宽) + Noto Sans SC(中文)
- 氛围：CRT 扫描线 + 微细网格 + 四角色散 + 偶尔噪点条纹

### Silent Signal（极简禅意）
- 适用：白天、冷静决策、情绪恢复
- 配色：米白 `#F5F0EB` + 纯黑 `#1A1A1A` + 淡墨 `#D0CBC5`
- 字体：Noto Serif SC(标题) + Inter 300(正文)
- 氛围：纸张纤维纹理 + 淡墨点装饰 + 超大留白

## 六个页面状态

### ① Oracle Splash
- 全屏居中一句随机开场白，3 秒自动过渡
- 文字下微光点呼吸动画
- 零按钮、零导航

### ② 主题选择
- 三张卡片纵向排列(手机)
- 每张：主题名 + 适用场景 + 装饰元素
- 根据时间智能默认高亮
- 选中：发光边框 + scale(1.02)

### ③ A/B 决策输入
- 两栏输入(手机端上下排列)
- 分隔符按主题变化(金线/终端光标/墨点)
- 主题化 placeholder

### ④ 信号采样（逐个浮现提问）
- 每次只显示一个提问，从 blur + noise 中凝结浮现
- 用户回答(chip 点击或短文本) → 收束消散 → 下一个浮现
- 底部 4 个微光点显示进度
- 提问文字 1.5rem(手机), 居中

### ⑤ Loading 仪式
- 全屏遮罩
- 主题特定动画 + AI 随机生成环境熵文案(3s 切换)
- Mystic Void: 粒子向心聚拢
- Neon Entropy: 扫描线加速 + hex 流
- Silent Signal: 墨点呼吸

### ⑥ 结果神谕卡片
- 世界偏向 A/B + 命运判词 + 信号解读
- 可截图分享卡片
- 重新决策按钮

## 技术架构

- 后端：Node.js + Express
- AI：DeepSeek API (deepseek-chat)
- 前端：Vanilla HTML/CSS/JS SPA，hash 路由
- 主题系统：CSS 自定义属性 + `data-theme` 属性切换
- 无框架依赖，纯静态 + API 调用

---

## AI Prompt 系统

三套系统提示：
1. **环境熵观测器 Prompt** — 生成随机信号采样问题 + Loading 文案 + 结果判词
2. 每次提问和结果都从随机池中动态生成，绝不重复模板
3. 语言风格：半科学半宿命，禁止客服/教育/论文语气
